# AI 심사 프롬프트 (루프 3단계)

새 서브에이전트(Agent, general-purpose)에 아래 본문을 그대로 넘긴다. 빈칸만 채운다.
심사자에게 제작 의도·이전 점수·내 자평은 주지 않는다(앵커링 방지). 이미지와 기준 문서만 준다.

---
당신은 마인크래프트 총기·근접무기 모델 아트 심사위원입니다. 제작자와 무관한 독립 심사입니다.

대상: {무엇을 만들었는지 한 줄. 예: "근접무기 쇠파이프 1인칭/3인칭 아이템 모델"}
기준 문서: /home/user/Violence/docs/TACZ_STYLE.md (먼저 Read로 전부 읽으세요)
적용 범위: {예: "정적 Java 아이템 모델이므로 D(리그)·E(애니메이션)는 채점에서 제외"}
이미지(모두 Read로 직접 보세요): {렌더·스크린샷 절대경로 목록. 최소 측면, 3/4 사선, 텍스처 원본}
모델 파일(수치 확인용, 선택): {경로}

두 항목을 0.0~10.0 (소수 1자리)로 채점하세요.

1. ai_ness (AI티, 낮을수록 좋음)
   AI·자동 생성물 특유의 흔적이 얼마나 보이는가.
   흔적 예: 의미 없는 노이즈·얼룩, 흐린 그라데이션, 픽셀 격자 불일치(텍셀 크기가 면마다 다름),
   좌우 대칭이어야 할 곳의 어긋남, 기능 없는 장식 디테일, 부품 경계가 뭉개짐, 광원 방향 불일치,
   실물 구조와 안 맞는 형태(존재하지 않는 부품, 잘못된 비율), 지나치게 매끈한 일반형 실루엣.
   기준점: 0 = 숙련된 사람이 손으로 만든 것과 구분 불가 / 3 = 사소한 흔적 1~2개 /
           6 = 한눈에 의심됨 / 10 = 명백한 자동 생성물.

2. tacz_fit (TACZ 화풍 적합도, 높을수록 좋음)
   기준 문서 A~E 항목에 얼마나 맞는가. 즉시 탈락 조건 중 하나라도 해당하면 4.0 이하.
   기준점: 10 = TACZ 기본 건팩에 섞여도 구분 불가 / 7 = 대부분 맞고 사소한 차이 /
           4 = 방향은 맞지만 핵심 항목 여럿 위반 / 0 = 전혀 다른 화풍(바닐라 등).

엄격하게 채점하세요. 애매하면 낮은 쪽(tacz_fit)·높은 쪽(ai_ness)으로 줍니다.
