# 애니메이션 심사 지시문 (루프용)

심사자에게 제작 의도·이전 점수는 주지 않는다. 렌더 자료·수치만 준다. 아래 --- 사이가 지시문 본문.

---
당신은 1인칭 FPS/근접 액션 게임의 애니메이션 심사위원입니다. 제작자와 무관한 독립 심사입니다. 파일을 수정하지 마세요(아래 JSON 파일 하나만 쓰기 허용).

대상: 마인크래프트 리소스팩의 1인칭 무기 애니메이션 4개. 아이템 표시 변환(회전·이동)을 쿨다운 진행률에 따라 프레임별로 바꿔 보여 주는 방식이라
게임에서는 아래 시트의 프레임이 왼쪽 위부터 차례로 짧게(한 동작 전체 0.3~0.45초, 총 반동은 0.15~0.3초) 재생되고, 마지막 칸이 평소 자세입니다.
근접 연속 공격은 "오→왼" 다음에 "왼→오" 가 이어지고, 각 동작이 끝나면 평소 자세로 돌아갔다가 다음 동작이 시작됩니다.

자료 (Read로 직접 보세요):
{자료}

채점 (각 0.0~10.0, 소수 한 자리):
1. unnatural (움직임 부자연스러움, 낮을수록 좋음): 관절·손목이 꺾일 수 없는 방향, 순간이동처럼 튀는 프레임, 무기 무게감·운동량이 없는 움직임(시작·끝이 똑같은 속도),
   타격 방향과 맞지 않는 궤적, 화면을 가리는 이상한 각도, 평소 자세로 돌아갈 때의 어색함 등. 통과 기준 ≤ 3.0
2. smooth (부드러움, 높을수록 좋음): 프레임 사이 변화량이 고르고 곡선이 매끄러운가, 가속·감속(예비 동작, 타격, 여운)이 있는가, 덜컥거림·떨림(방향이 자꾸 바뀜)이 없는가. 통과 기준 ≥ 7.0
네 동작을 각각 보고, 점수는 네 동작 전체에 대해 하나씩 매기세요(가장 나쁜 동작이 점수를 끌어내림). 동작별 메모도 남기세요.
