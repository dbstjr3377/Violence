# 루프 제작 절차 ("루프로 진행해줘")

사용자가 요청한 결과물(모델·맵·이미지·텍스처 등) 뒤에 "루프로 진행해줘"가 붙으면 이 절차를 따른다.
한 번 만들고 끝내지 않는다. **20회**를 모두 돌린다(중간에 통과해도 계속 개선하며 20회 채움).
사용자가 중간에 멈추라고 하면 그 자리에서 멈추고 지금까지의 통과 스냅샷을 보고한다.

## 준비 (0회차)
1. slug 정하기: 영문 소문자-하이픈, 예 `pipe-melee`. 
2. `python3 tools/loop/loop_snap.py init <slug> "<요청 원문>"`
3. 기준 문서 `docs/TACZ_STYLE.md`를 읽는다. 대상이 총기·근접무기가 아니면(맵, 이미지 등)
   TACZ 화풍 항목 중 적용 가능한 것(텍셀 밀도, 단색 면, 면 방향 명암, 팔레트, 노이즈 금지)으로 판정한다.

## 도구 규칙
- 모델 작업(제작·수정·검사·렌더·내보내기)은 **블록벤치 MCP(blockbench-headless)** 로만 한다.
  원본은 `loop_runs/<slug>` 스냅샷에 `.bbmodel` 로 남기고, 심사용 렌더는 `bbmodel_render`/`bbmodel_contact_sheet`,
  검사는 `bbmodel_validate`, 팩용 JSON 은 `bbmodel_export_java_block` 으로 만든다.

## 회차 N (1~20) — 매 회차 동일
0. **제작/수정**: 1회차는 새로 만든다. 2회차부터는 "지금까지 종합점수(TACZ−AI)가 가장 높은 스냅샷"을
   출발점으로 삼아(필요하면 `restore`) 직전 심사의 `top_fixes`와 잡티 불합격 항목을 고친다.
   한 회차에 한 방향의 큰 수정 1~3개만 한다(무엇이 점수를 바꿨는지 알 수 있게).
1. **스냅샷**: `python3 tools/loop/loop_snap.py save <slug> <N> <결과물 파일...>`
   렌더·스크린샷은 `attach <slug> <N> <png...>`. 결과물은 레포 안 경로여야 한다.
2. **잡티 검사(코드)**:
   `python3 tools/loop/speck_check.py --model <모델> <텍스처.png> --json <scratchpad>/speck_N.json`
   (모델 없는 이미지·맵 텍스처는 `--model` 없이). 고립 픽셀, 면 안 구멍, 반투명, 노이즈·디더링, 5색+ 면 비율을 본다.
3. **AI 심사**: 렌더 이미지(측면, 3/4 사선, 텍스처 원본 최소 3장)를 만들고,
   `tools/loop/judge_prompt.md` 본문을 채워 **새 서브에이전트**에 넘긴다. 이전 점수·제작 의도·내 자평은 주지 않는다.
   돌려받은 JSON을 `<scratchpad>/judge_N.json`으로 저장.
   - AI티(ai_ness) 0.0~10.0, **통과 ≤ 3.0**
   - TACZ 화풍(tacz_fit) 0.0~10.0, **통과 ≥ 7.0**
   - 잡티 검사도 통과해야 최종 통과.
4. **기록**:
   `python3 tools/loop/loop_snap.py record <slug> <N> --speck <speck_N.json> --judge <judge_N.json> --ai <x> --tacz <y> --blocker "<막힌 곳>" --fix "<이번 회차에 뭘 왜 고쳤나>" --next "<다음 회차 계획>"`
   → `loop_runs/<slug>/LOG.md`(항목별 점수·막힌 곳·수정 이유), `PASSED.md`(통과 스냅샷 목록)가 자동 갱신된다.
5. 사용자에게 한 줄 진행 보고: `회차 N/20: 잡티 P/F, AI티 x, 화풍 y → 통과/불합격 (막힌 곳)`.

## 끝난 뒤
- 최종 결과물 = PASSED.md 1순위 스냅샷. `restore`로 레포에 적용하고 빌드·검증(`tools/verify_all.sh`) 후 커밋·푸시.
- 보고: 통과 스냅샷 번호 목록과 점수, 최종 선택 이유, LOG.md 경로, 대표 렌더 이미지.
- 통과한 회차가 하나도 없으면 그렇게 말하고, 가장 가까운 스냅샷과 막힌 원인을 보고한다.
- `loop_runs/<slug>/`는 커밋한다(나중에 되돌리기 위해).

## 추가 요청 받기 (5단계)
- "snap_07로 돌아가 적용해줘" → `loop_snap.py restore <slug> 7` 후 빌드·검증·커밋.
- "snap_07부터 다시 작업해줘" → restore 후 회차 번호를 이어서(21, 22, …) 같은 절차로 진행.
  사용자가 횟수를 정하지 않으면 20회.

## 금지
- 심사 점수를 직접 매기거나 고치지 않는다(반드시 서브에이전트 심사 결과 그대로 기록).
- 잡티 검사 기준값(`LIMITS`)을 루프 도중에 완화하지 않는다.
- TACZ 파일을 복사하지 않는다(GPL-3.0). 기준만 참고.
