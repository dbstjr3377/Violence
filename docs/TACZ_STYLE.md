# TACZ풍 모델 판단 기준

출처: TACZ 1.2.0 기본 건팩(GPL-3.0) 총 71정·대검 2종·애니메이션 71개 파일 실측.
**기준만 참고한다. TACZ 모델·텍스처·애니메이션 파일을 복사하거나 변형해 쓰지 않는다.**

한 줄 요약: 형태는 지오메트리로, 색은 면마다 거의 단색으로, 명암은 면 방향별로 미리 칠한 하이디테일 큐브 모델.

## A. 모델(지오메트리)
| 항목 | TACZ 실측 | 합격선 |
|---|---|---|
| 큐브 수 | 총 203~1770, 중앙값 709 / 대검 39~43 | 총 300+, 근접무기 30+ |
| 본 수 | 총 32~236, 중앙값 79 / 대검 2~4 | 움직이는 부품마다 본 분리 |
| 얇은 부품 | 큐브 97%가 한 변 1px 미만, 최소 변 중앙값 0.19px | 90%+가 1px 미만 |
| 회전 큐브 | 약 60%, 45°가 압도적 | 40%+ |
| 모서리 깎기 | 0.177px(0.25÷√2) 큐브를 45°로 모서리에 붙임 | 각진 박스만이면 불합격 |
| 원통 | 같은 큐브를 45°씩 돌린 8각 단면(총열·손잡이·링) | 최소 8각 |
| 치수 | 74%가 0.25 격자 밖 자유 치수, 겹침은 inflate ±0.001~0.01 | 정수 격자 블록 느낌이면 불합격 |
| 크기 | 길이 12~40px, 중앙값 17 | 권총·SMG ~12, 소총 17~20 |

## B. 텍스처
| 항목 | TACZ 실측 | 합격선 |
|---|---|---|
| 밀도 | UV 128/256, PNG는 2배(57정)·4배 → 모델 1px당 2~4텍셀 | 1px당 2텍셀+ (바닐라 16px 밀도 불합격) |
| UV | 모든 면 면별 UV(box UV 0) | 면별 UV |
| 면 색 | 단색 ~70%, 2~4색 ~20%, 5색+ <10% | 노이즈·질감 칠하기 없음. 디테일은 형태로 |
| 명암 | 면 방향별로 미리 칠함. AK: 위 76 / 앞 65 / 옆 58~62 / 뒤 53 / 밑 47 | 윗면 +15~25%, 밑면 −15~25% (옆면 대비) |
| 테두리 하이라이트 | 거의 없음(<2%) | 밝은 외곽선 금지 |
| 팔레트 | 회색이 면의 70~93%, 나머지 적갈색 목재(80,48,48)·청회색 강철 | 무채색 중심 + 재질 포인트 1~2색 |
| 명도 | 평균 V 0.28, 픽셀 ~51%가 V<0.25, 평균 채도 0.13 | 평균 V ≤0.35, 채도 ≤0.25 |
| 금속 하이라이트 | 연마면 (144~160), 대검 날 (192~224) 푸른 기 | 최고 명도는 날·연마면에만 |
| 보조 맵 | `_n`(노멀), `_s`(스페큘러) 동일 크기 | 선택 |

## C. 근접무기 (대검 M9·6H3 기준)
- 날: 큰 판 1~2장(두께 0.25) + 0.177 크기 45° 큐브 칼날선 + 혈조 홈.
- 손잡이: 0.875 큐브를 길이축 45° 회전한 8각 원통 + 1.0~1.25 링 마디.
- 가드: 날과 별도 판.
- 색: 날 V 0.45~0.7, 날 끝 0.75~0.88, 손잡이 V 0.12~0.2 (명도 차 크게).

## D. 리그
- 필수: `root`, `camera`, `constraint`, `lefthand`/`righthand`(+`_pos`).
- 위치용 빈 본: `muzzle_pos`, `shell`, `idle_view`, `iron_view`.
- 움직이는 부품: `magazine`/`mag_and_lefthand`, `bolt`/`slide`, `trigger`, `hammer`, `bullet_in_mag`/`bullet_in_barrel`, `additional_magazine`.
- 손과 함께 움직이는 부품은 손과 같은 체인에 묶음.

## E. 애니메이션
| 클립 | 길이(중앙값, 범위) |
|---|---|
| draw | 0.78초 (0.54~2.05) |
| put_away | 0.5초 |
| shoot | 0.67초 (0.17~1.37) |
| reload_tactical / reload_empty | 2.4초 / 3.0초 |
| inspect | 7.7초 (4.3~13.9) |
| melee_push | 0.92초 |

- 보간: root·camera·손은 catmullrom, 노리쇠·슬라이드는 선형 순간 이동(예: 0→6→0px를 0.067초에).
- 키 간격: 반동 1/60초, 근접 1/24초.
- 반동: root 위로 −1.7°(AK)~−10~12°(권총·샷건), 뒤로 1~4px, camera 롤 ±1~2°, 0.3~0.7초 감쇠 진동.
- 꺼내기: 좌하단 (−5,−14,0)·기울임 (22,−22,32)에서 ~0.3초에 올라와 살짝 오버슈트. camera ≤1.1°.
- 근접: 0.04초 13px 예비 동작 → 0.08초에 75~100° 휘두름 → camera 3° → 0.9초 안에 감쇠 복귀.

## 종합 판정
A~E 항목을 0/1로 채점해 80%+면 TACZ풍. 아래 중 하나라도 해당하면 즉시 탈락:
- 바닐라 수준 텍셀 밀도
- 노이즈 텍스처로 디테일 표현
- 원통·모서리를 8각/45° 깎기 없이 각진 박스로 처리

## 자동 검사
- 잡티: `python3 tools/loop/speck_check.py --model <모델> <텍스처.png>`
  (TACZ 원본 71정 중 55정 통과. 나머지 16정도 실제 1~17픽셀 구멍이 있는 경우)
