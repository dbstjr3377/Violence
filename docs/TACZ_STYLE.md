# TACZ풍 모델 판단 기준 (2판)

출처: TACZ 1.2.0 기본 건팩(GPL-3.0) 총기 71정·대검 2종. 2판은 TACZ 모델을 블록벤치로 옮겨 **텍스처를 입힌 채**
렌더해 보고(`tools/loop/tacz_ref.py`), 4×4텍셀 이상 **큰 면만** 따로 재서 고쳤다.
**기준만 참고한다. TACZ 모델·텍스처·렌더 이미지를 레포에 넣거나 변형해 쓰지 않는다.**

## 1판에서 틀렸던 것
| 1판 | 실제 (2판) | 왜 틀렸나 |
|---|---|---|
| 면의 ~70% 단색, 노이즈 칠하기 없음 | 큰 면은 단색 2~30%, 나머지는 텍셀 단위 미세 얼룩 + 그라데이션 | 1~2텍셀짜리 작은 면이 집계 대부분을 차지 |
| "노이즈 텍스처 = 즉시 탈락" | 미세 얼룩이 TACZ 화풍의 핵심 | 위와 같음 |
| 면 방향 명암을 미리 칠함 (위 +20% / 아래 −20%) | 총마다 제각각 (AK 위 0.23 < 옆 0.27, M870 위 0.15 < 옆 0.22) | 면 평균만 보고 렌더를 안 봄. 방향 명암은 게임 조명이 낸다 |
| 텍셀 밀도 2~4 | **2텍셀/px 가 표준** (57/71정), 4는 부착물·근접 위주 | — |
| 큐브 300+ 이면 충분 / 중앙값 709 | 보이는 큐브(손·확장탄창·탄 제외) 중앙값 500. 권총·SMG 180~420, 소총 500~800 | 숨겨진 부품까지 셌음 |

## 한 줄 요약
**아주 어두운 금속(평균 V ≈0.2~0.28)에 텍셀 단위로 아주 약한 얼룩과 긴 그라데이션을 칠한 픽셀 아트 텍스처,
2텍셀/px 밀도, 실물 비율의 덩어리 형태(45° 깎기·팔각), 작은 원색 포인트(가늠자 점·그립 띠).**

## A. 모델(형태)
| 항목 | TACZ 실측 | 합격선 |
|---|---|---|
| 보이는 큐브 수 | 권총 180~400, SMG 290~760(우지 309, MP5 762), 샷건 ~200, 소총 500~800 | 종류별 범위 안 (많을수록 좋은 게 아님) |
| 얇은 부품 | 큐브 대부분이 한 변 1px 미만 | 90%+ |
| 회전 | 모서리 45° 깎기·팔각 원통이 주, 실물 곡선(탄창 곡률, 개머리 지지대)은 여러 각 | 원통·모서리를 각진 박스로 두면 감점 |
| 넓은 면 | 리시버 옆면 같은 큰 평면이 흔함 — 디테일은 텍스처 얼룩·그라데이션이 채움 | 큰 평면 자체는 감점 아님 |
| 실루엣 | 실물 비율, 덩어리감. 둥근 가늠자 후드(팔각 고리+구멍), 개머리 지지대 사선 등 특징 부품을 또렷하게 | 기능 없는 장식·떠 있는 부품이면 감점 |

## B. 텍스처 (가장 중요)
측정: `tools/loop/tacz_texstats.py`, 4×4텍셀 이상 **큰 면**만. 아래 범위는 TACZ 총기 71정 분포의 p10~p90.

TACZ 텍스처는 두 갈래다. **얼룩·그라데이션형**(35정: 우지·AK·M870·MP5 등, 큰 면 단색 ≤35%)과
**단색형**(36정: 글록·데저트이글·AUG 등, 큰 면 단색 36~62%). 공통점은 2텍셀/px, 어두운 금속, 윗모서리 밝은 줄,
그리고 **큰 면이 전부 단색인 총은 하나도 없다**는 것이다.

| 항목 | TACZ 분포 (p10 / 중앙 / p90) | 합격선 |
|---|---|---|
| 텍셀 밀도 | 2.0 / 2.0 / 4.0 (57정이 2) | 1.5~4.5, **2 권장** |
| 큰 면 단색 비율 | 0.04 / 0.36 / 0.62 | ≤ 0.62 |
| 얼룩 (그라데이션 뺀 V 표준편차) | 0.00 / 0.021 / 0.056 | 얼룩 ≥ 0.01 또는 그라데이션 ≥ 0.02 |
| 그라데이션 폭 (면 안 V 변화) | 0.00 / 0.028 / 0.081 | (위와 함께) |
| 윗모서리 밝은 줄 (큰 면 중) | 0.05 / 0.18 / 0.37 | 0.05~0.37 |
| 평균 V | 0.20 / 0.28 / 0.39 | 0.20~0.39 |
| 면끼리 명도 대비 (면 평균 V 표준편차) | 0.067 / 0.115 / 0.19 | 참고 (부품마다 밝기 단계가 분명) |
| 얼룩의 성격 | 밝기만 텍셀 단위로 살짝 흔듦, 같은 값이 가로로 이어지는 길이 중앙 1텍셀 | 색상 노이즈·고대비 점 금지 |
| 면 방향 명암 | 미리 칠하지 않음 (위/옆/아래 평균이 총마다 다름) | 위·아래 일괄 ±20% 칠하기 금지 |
| 포인트 색 | 가늠자 점(초록·빨강), 그립 띠(황동·금색) 등 아주 작은 면적 | 1~2색, 면적 5% 이하 |
| 나무 | 적갈색, 금속보다 얼룩이 강함 (AK) | — |

**통과: 위 5개 검사(단색 비율·얼룩/그라데이션·윗모서리 줄·텍셀 밀도·평균 V) 중 1개까지 어긋나도 됨.**
TACZ 원본 71정 중 61정(86%)이 통과한다. 1판 기준으로 만든 소방도끼(3개 어긋남)·우지(4개)는 불합격.

## C. 근접무기 (대검 M9 기준, 4텍셀/px)
- 큰 면 단색 42%, 세로 그라데이션 32%: 칼날은 길이 방향 그라데이션, 손잡이는 마디마다 명암.
- 날 끝 한 줄 밝은 연마선, 손잡이 체크 무늬(널링)는 텍스처로.
- 형태: 날 판 1~2장 + 45° 칼날선, 팔각 손잡이 + 링 마디.

## D·E (리그·애니메이션) — 정적 아이템 모델이면 채점 제외
1판 내용 유지: 본 `root/camera/lefthand/righthand/...`, 반동 −1.7~−12°, 꺼내기 ~0.78초 등.

## 심사 방법 (루프)
- 심사자에게 **TACZ 참고 렌더**(같은 렌더러·같은 조명)를 함께 보여 준다: `python3 tools/loop/tacz_ref.py`
  (TACZ jar 를 따로 받아 풀어 둔 경로가 필요. 결과는 스크래치패드에만 저장, 레포에 넣지 않음)
- 수치 검사: `python3 tools/loop/tacz_texstats.py --model <모델.json> <텍스처.png>` 로 위 B 표 항목을 잰다.
  심사자에게 이 결과 JSON 도 같이 준다.
- 즉시 탈락: ① 텍스처 수치 검사 불합격(5개 중 2개 이상 어긋남 — 큰 면이 전부 단색이면 여기 걸림)
  ② 고대비·색상 노이즈 ③ 원통·모서리를 각진 박스로만 처리
