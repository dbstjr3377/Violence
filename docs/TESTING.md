# 인게임 테스트 체크리스트

개발 환경에서는 실제 서버와 클라이언트를 실행할 수 없었습니다. 그래서 아래 항목은 직접 접속해서 확인해 주세요.
문제가 있으면 항목 번호와 증상(가능하면 스크린샷과 서버 로그)을 알려 주시면 고치겠습니다.

## 0. 준비
1. `bukkit/setup.sh`를 실행하고, `eula.txt`를 `eula=true`로 바꾼 뒤 `start.sh`로 서버를 엽니다.
2. 서버 로그에 아래 두 줄이 나오는지 확인합니다.
   - `VIOLENCE 활성화 - 무기 32종, 맵 8개`
   - `리소스팩 HTTP 서버 시작: 포트 8163`
3. Skript 로그에 `game.sk`, `score.sk`, `messages.sk`가 오류 없이 로드되는지 확인합니다.
4. 접속하면 리소스팩 적용 화면이 뜨는지 확인합니다.
5. `/vio info`의 "Skript 연동"이 `사용 중`인지 확인합니다.

## 1. 기본 진행
- [ ] `/vio map generate all`: 8개 맵이 모두 생성되고 크기와 개수 정보가 출력된다.
- [ ] `/게임시작 club 10 180`: "플레이어 n + NPC (50-n)" 안내, 3·2·1 카운트다운, KILL 제목이 차례로 나온다.
- [ ] 상단 보스바에 남은 시간, 목표 킬, 1위, 내 킬과 점수가 보인다.
- [ ] 목표 킬을 달성하거나 시간이 끝나면 GAME OVER와 순위가 나오고, 8초 뒤 로비로 돌아간다.
- [ ] `/게임중단`: 즉시 로비로 돌아가고 게임 월드가 정리된다.

## 2. 이동과 입력
- [ ] 점프와 달리기가 되지 않고, 기본 이동이 평소보다 빠르다.
- [ ] 핫바 슬롯을 바꿀 수 없고, F(손 바꾸기)와 Q(버리기)가 막혀 있다.
- [ ] 벽을 조준하고 왼클릭을 누르고 있으면 M16·UZI·MP5가 연사된다.
- [ ] 샷건·피스톨·매그넘은 클릭할 때마다 한 발씩 나간다.
- [ ] 바닥 무기를 조준하면 하얀 테두리로 빛나고, 우클릭으로 주워진다.
- [ ] 바닥 무기를 조준하면 무기 오른쪽에 검은 단색 카드가 뜬다: 왼쪽 위 무기 종류(회색), 이름(흰색), 왼쪽 아래 우클릭 아이콘 + "줍기"(회색), 오른쪽 아래 현재 / 최대 탄수(총만). "줍기"와 탄수가 겹치지 않고 각각 카드 양 끝에 붙는다. 카드는 나에게만 보이고, 조준을 떼면 사라진다.
- [ ] 탄이 빈 총을 조준하면 테두리가 빨간색이고 카드의 탄수(0 / 최대)도 빨간색이다.
- [ ] 무기를 든 채 바닥 무기를 조준하고 우클릭하면, 던진 뒤 곧바로 줍는다.
- [ ] 같은 자리에 무기가 겹쳐 있으면 가장 나중에 떨어진 것부터 주워진다.

## 3. 무기 모델 (리소스팩)
- [ ] 1인칭 총: 화면 오른쪽 아래에서 장갑 낀 양손으로 총을 쥐고 화면 중앙을 겨눈다. 위치는 `docs/images/firstperson/` 시뮬레이션과 비교한다.
- [ ] 쏘는 순간 총구에 노란 화염이 보이고 총이 뒤로 튀었다가 제자리로 돌아온다(반동 잡기). 조준점은 움직이지 않고, 손이 내려갔다 올라오는 깜빡임이 없어야 한다.
- [ ] 1인칭 총의 총열 끝이 화면 중앙(조준점)을 향한다.
- [ ] UZI·M16을 꾹 누르면 총구 화염이 깜빡이며 총이 떨리고, 노란 궤적이 총구에서 조준점 쪽으로 나간다. 화면이 크게 흔들리지 않는다.
- [ ] 1인칭 근접 무기: 오른손으로 쥐고 있고, 공격하면 오른쪽에서 왼쪽으로 길게 벤다. 부러진 큐대는 찌르기다.
- [ ] 왼클릭을 계속 누르면 오→왼, 왼→오가 번갈아 나오고 하얀 베기 궤적도 방향이 바뀐다. 동작이 바뀔 때 손이 내려갔다 올라오는 깜빡임이 없어야 한다.
- [ ] 도끼날, 망치 머리, 골프채 헤드가 베는 방향(왼쪽)을 향한다. 서류가방은 아래쪽 손잡이를 쥐고 있다.
- [ ] 맨손: 장갑 낀 두 주먹이 보이고, 왼클릭하면 잽, 무기를 던지면 팔을 뻗는 동작이 나온다. 3인칭에서는 손에 아무것도 보이지 않는다.
- [ ] 3인칭과 다른 플레이어 시점에서도 손에 제대로 들려 있다.
- [ ] 바닥에 떨어진 무기가 바닥에 눕혀져 있다.
- [ ] 가면을 쓰면 머리 위치에 맞게 보인다.

모양이 어긋나면 `tools/pack_models.py`의 `*_DISPLAY` 값만 조정하면 됩니다.

## 3-1. 3인칭 상체 애니메이션 (두 명이 서로 확인)
- [ ] 상대가 M16·UZI·MP5·샷건·더블배럴을 들면 양팔로 겨누는 자세가 되고, 걸을 때 다리는 따로 움직인다.
- [ ] 권총(매그넘, 소음기 권총)은 한 팔을 앞으로 들어 겨누고, 다른 팔은 내려가 있다. 이때 소리나 입자가 나지 않는다.
- [ ] 상대가 근접 무기를 들면 두 손으로 손잡이를 위아래로 겹쳐 잡고, 오른손이 위에 있다. 무기가 오른쪽 어깨 쪽으로 기운다. 반짝임이 없다.
- [ ] 상대가 근접 무기로 공격하면 오른팔이 휘두르고 몸통이 비틀리며, 무기가 어깨 뒤로 젖혀졌다가 오른쪽에서 왼쪽으로 옆으로 크게 지나간다. 끝나면 왼쪽 어깨 쪽 대기 자세가 된다.
- [ ] 이어서 공격하면 왼쪽에서 오른쪽으로 휘두르고 오른쪽 대기로 돌아온다 (1인칭 화면의 좌우와 같음). 이때도 오른팔이 휘두르고 오른손이 위다. 잠깐 쉬면 오른쪽 대기로 돌아온다.
- [ ] 왼팔이 따로 한 번 더 휘둘러지는 동작이 보이지 않는다 (클라이언트 휘두르기를 막음). 맨손·총·투척은 예전처럼 주 손이 휘두른다.
- [ ] 도끼·마체테·식칼은 날이 휘두르는 방향을 향한다. 휘두르는 도중 무기가 손에서 크게 떨어져 보이지 않는다.
- [ ] 부러진 큐대는 찌르기 동작이다.
- [ ] NPC도 같은 자세로 보인다.

## 4. 피격 / 쓰러짐 / 처형
- [ ] NPC의 머리를 맞히면 즉사하고, 몸통을 맞히면 뒤로 밀려나며 쓰러진다. 쓰러질 때 무기를 떨어뜨린다.
- [ ] 총은 쓰러뜨리지 않는다. 몸통 첫 발에는 잠깐 휘청이고, 두 번째 발(HP 30 이하)에 바로 죽는다. 머리는 한 발. 맞고 3초 동안 안 맞으면 HP가 회복되어 다시 두 발이 필요하다.
- [ ] 총이나 근접 무기로 죽으면 어느 방향에서 맞든 공격 방향으로 밀려나며 뒤로 넘어가 등으로 눕는다. 등 뒤에서 맞으면 맞은 쪽으로 돌아서며 뒤로 넘어간다 (0.3초 인형 동작 후 시체). 맨주먹·던지기·문에 맞아 쓰러질 때도 같다.
- [ ] 샷건·더블배럴로 죽이면 두 팔을 활짝 벌리고 뒤로 날아가 눕고, 팔이 바닥에서 내려온다.
- [ ] 벽 앞(뒤 1.7블록 안)에 선 적을 맞히면 벽에 부딪혀 미끄러져 내려와 벽에 등을 기대 앉는다(머리를 숙임). 움직이지 못하고 3초 뒤 일어선다. 유리창 앞에서는 기절하지 않는다.
- [ ] 벽 기절한 적에게 Space: 어떤 무기를 들었든 처형자가 앞에 서서 다리를 뒤로 당겨 잠깐 버틴 뒤 머리를 발로 찬다(옆에서 보는 처형 카메라). 머리가 젖혀지고 벽에 피가 튀고, 벽에 기댄 채 죽는다. 끝날 때 처형자 모습이 사라지지 않고 처형자 시점으로 돌아온다.
- [ ] 벽 기절한 적을 총이나 근접 무기로 맞히면 죽고, 벽에 기댄 채 시체로 남는다(피 웅덩이 없음).
- [ ] 모든 처형: 시작할 때 1인칭에서 처형 카메라 자리로 부드럽게(easeOutSine) 옮겨 가고, 끝나면(후딜레이 포함) 곧바로 처형자 시점으로 돌아온다.
- [ ] 총을 들면 화면 오른쪽 아래에 "현재/총" 탄수, 탄이 없으면 "탄 없음!", 샷건은 탄피 아이콘 게이지. 손에 든 무기 이름은 뜨지 않는다.
- [ ] 연속으로 빠르게 죽여도(붉은 연속킬 화면 중에도) 죽일 때마다 흑백 깜빡임이 나온다.
- [ ] 인형에서 누운 몸(스킨·가면·피 장비)으로 바뀔 때 자세가 튀지 않는다. 인형 색이 그 플레이어의 스킨과 비슷하다. NPC는 옷 색이 같다.
- [ ] 등으로 누운 플레이어가 기어가면 누운 몸이 따라간다. 3초 뒤 일어서면 실제 몸으로 돌아오고 손에 든 것과 장비가 다시 보인다.
- [ ] 누워 있을 때 처형하면 누운 몸 그대로 처형되고, 죽으면 그 몸이 시체로 남는다. 근접 무기·헤드샷으로 바로 죽여도 맞은 방향으로 넘어져 시체가 된다.
- [ ] 쓰러지고 3초가 지나면 일어나고, 그 직후 아주 잠깐 공격할 수 없다.
- [ ] 쓰러진 적 위에서 Space를 누르면 머리 쪽을 보고 올라타고, 시점이 처형자 오른쪽 옆 위로 바뀐다 (무기가 머리에 닿는 순간이 몸에 가리지 않음).
- [ ] 처형 무기가 손 안에서 휙 돌지 않는다: 들어 올린 무기가 위→앞→아래로 내려와 앞면(크로우바 갈고리·도끼날·식칼 날)으로 머리를 친다.
- [ ] 처형 인형의 팔이 팔꿈치에서, 다리가 무릎에서 굽는다: 올라탄 처형자는 무릎을 꿇고, 두 손 무기는 두 손이 손잡이를 잡은 채 팔꿈치를 굽혀 휘두른다. 팔·다리 마디 사이가 벌어지지 않는다.
- [ ] 맨손 처형: 두 손이 피처형자 머리 양옆을 잡은 채 머리를 들었다 바닥에 박는다. 코브라·돼지·곰 가면: 무릎을 굽혀 발을 머리 바로 위로 들었다가 내리찍는다.
- [ ] 넘어짐·벽 기절·발차기 동작이 예전과 같게 보인다 (인형이 10부위로 바뀌었지만 넘어지는 동작은 팔다리를 곧게 편 그대로).
- [ ] 마지막 타격 뒤 1인칭으로 돌아오면 내 발밑에 내 인형이 보이지 않는다 (다른 사람에게는 치는 동작이 마저 보인다).
- [ ] 처형 타격마다 피가 누운 몸의 머리에서 튄다 (발 쪽이 아님). 벽 기절 발차기도 머리에서 벽 쪽으로 튄다. 근접 무기·주먹으로 서 있는 적을 치면 얼굴 높이에서 피가 난다.
- [ ] 처형 방식이 무기 묶음마다 다르다 (처형자·피처형자 인형이 움직이고, 처형자 오른손에 무기가 보인다).
  - 맨손: 올라타 머리를 바닥에 박는다. 왼클릭 5번, 박을 때마다 머리 밑에 피.
  - 맨손 + 코브라·돼지·곰 가면: 머리 옆에 서서 한쪽 다리를 든 채 시작해 자동으로 밟는다. 양옆으로 피가 튄다.
  - 둔기(쇠파이프·몽둥이·골프채·삼단봉·망치·서류가방·크로우바): 두 손으로 높이 든 채 시작, 왼클릭 3번 내려친다. 무기 끝이 머리에 닿는다.
  - 무거운 무기(카타나·당구 큐대·오함마·소방도끼): 자동으로 한 번 크게 내려치고, 흔들어 뽑아 올린다. 흔들 때·뽑을 때 피가 난다.
  - 가벼운 무기(냄비·프라이팬·마체테·중식도): 오른손만으로 왼클릭 3번 내려친다.
  - 날붙이(단검·짧은 큐대): 칼날을 목에 댄 채 시작해 자동으로 목을 긋는다. 목에서 피가 뿜어져 나온다.
  - 총·투척 무기: 무기를 버리고 맨손 처형으로 바뀐다 (형사 가면은 총으로 처형).
  - 벽에 기대 기절한 적은 무기·가면과 상관없이 발차기로 처형된다.
- [ ] 오함마가 맵에 놓이고, 1·3인칭 모델과 휘두르기가 보인다.
- [ ] 처형 중 우클릭하면 내려온다.
- [ ] 처형이 끝나면 원래 1/3인칭 시점으로 돌아간다.
- [ ] 사망하면 앞·위 시점, 검은 화면, 2초 뒤 리스폰이 차례로 진행되고 원래 시점으로 돌아온다.

## 4-1. NPC 시작 무기
- [ ] 게임을 시작하면 NPC 5명 중 3명꼴로 무기를 들고 있다 (10명이면 무기 6명: 총 2명·근접 4명, 맨손 4명).
- [ ] 무기를 든 NPC가 처음부터 그 무기로 싸운다 (총은 쏘고, 근접 무기는 휘두름). 리스폰한 NPC도 같은 비율로 무기를 든다.

## 5. 문 / 유리
- [ ] 닫힌 문으로 걸어가면 밀려서 열리고, 닫힌 문은 통과할 수 없다.
- [ ] 문을 쏘면 총알 방향으로 열린다.
- [ ] 문 앞에서 Space를 누르면 발차기로 크게 열리고, 문에 맞은 NPC가 쓰러진다.
- [ ] 유리창을 쏘거나 때리면 파편과 함께 깨지고, 총알은 그대로 관통한다.

## 6. 연출 / 점수
- [ ] 총알 궤적이 노란 선으로 날아가고, 매그넘은 주황색이다.
- [ ] 맞히면 핏방울이 공격 방향으로 포물선을 그리며 날아가고, 바닥·벽에 닿은 자리에 그 면에 맞는 혈흔이 생긴다.
- [ ] 혈흔은 한 가지 빨강의 또렷한 픽셀 그림이다(덩어리 + 네모난 조각). 바닥에 곧게 떨어지면 둥근 얼룩과 튄 방울, 비스듬히 닿으면 넓게 퍼진 얼룩(가늘고 긴 꼬리가 아님), 벽에서는 아래로 흘러내리는 줄기, 헤드샷·처형은 흩뿌린 조각이 보인다.
- [ ] 튄 혈흔은 5초 뒤 서서히 투명해지며 사라진다.
- [ ] 처형당한 시체의 머리에서 바닥으로 피가 천천히 흘러 퍼진다.
- [ ] 조준점이 십자가 아니라 작은 점이다.
- [ ] 총으로 맞히면 조준점에 흰색 히트마커가 잠깐 보이고, 처치하면 같은 흰색에 조금 더 굵은 히트마커가 보인다.
- [ ] 적을 죽이면 0.3초 동안 화면 안의 모든 것(맵, 인물, 시체, 혈흔, 손에 든 무기, 입자, 하늘)이 흑백으로 깜빡이고 원래대로 돌아온다. 핫바·HUD 글자·UI는 색 그대로다. 야간 투시 아이콘·입자는 보이지 않고, 깜빡이는 동안 화면이 눈에 띄게 밝아지지 않는다.
- [ ] 처치하면 시체 위에 점수가 0.8초 동안 나타난다(죽인 사람에게만 보임).
- [ ] 10초 안에 연속 처치하면 좌상단에 콤보가 나오고, 콤보가 끝나면 보너스 점수가 왼쪽에서 미끄러져 나온다.
- [ ] 연속 킬에 따라 효과가 강해진다.
  - 1킬: 몸에 피가 묻는다.
  - 3킬: 화면이 붉게 물들고 흔들린다.
  - 5킬: 효과가 더 강해지고 심장 박동 소리가 난다.
- [ ] 3킬과 5킬을 달성하면 화면 중앙 하단에 "E키를 눌러 가면을 착용하세요"가 1초 동안 뜬다. E를 누르면 가면 3개 중 하나를 고를 수 있다.

## 6-1. 클럽 조명 쉐이더 (`/게임시작 club`)
- [ ] 클럽 안에서 화면이 어두워지고, 천장의 색 원뿔이 바닥과 벽을 쓸고 다닌다. 공중에 보이는 빛줄기와 바닥의 빛 자국이 같은 곳을 가리킨다.
- [ ] 미러볼 빛 점이 벽과 바닥에서 천천히 돈다.
- [ ] 댄스 플로어 타일이 박자에 맞춰 색이 바뀐다.
- [ ] 약 7.5초 간격으로 레이저가 켜지고 꺼진다. 켜지면 DJ 부스에서 초록·빨강 레이저가 나오고, 벽과 바닥의 선과 이어진다.
- [ ] 다른 맵과 로비는 평소처럼 보인다(조명 효과 없음).
- [ ] 그래픽 설정을 바꿔도(빠름, 화려함, 반투명 처리 방식) 화면이 깨지거나 검게 나오지 않는다. 게임 로그(`logs/latest.log`)에 쉐이더 오류가 없다.
- [ ] 문제가 있으면 F3+T(리소스 새로고침) 뒤 로그의 쉐이더 오류 줄을 보내 주세요.

## 6-2. 벅샷 룰렛 색감 (`/게임시작 apartment_a`, `apartment_b`, `prison`)
- [ ] 천장 전구 아래는 따뜻한 노란빛, 나머지는 녹청색으로 보이고 화면이 너무 어둡지 않다.
- [ ] 전구가 없는 방도 벽과 바닥이 보인다.
- [ ] 필름 그레인과 화면 가장자리 비네트가 보이고, 가끔 전구가 깜빡인다.
- [ ] 클럽과 나머지 맵에는 이 색감이 나오지 않는다.
- [ ] 랜턴이 길을 막거나 머리에 걸리지 않는다.

## 6-3. 컷씬 다이얼로그 (로비에서 `/컷씬`)
- [ ] 게임 중에는 `/컷씬`이 거부되고, 컷씬 중에는 `/게임시작`이 거부된다.
- [ ] 시작하면 다른 플레이어는 관전 모드로 카메라에 붙고(핫바 안 보임), Shift로 빠져나갈 수 없다.
- [ ] 위아래 검은 띠가 들어오고, 오른쪽에서 자홍색 패널과 초상화가 미끄러져 들어온다. (관전 모드에서 띠가 안 보이면 `cutscene.spectate-viewers: false`로 바꿔 알려 주세요)
- [ ] 카메라가 대사의 대상 개체를 비추는 위치로 부드럽게(처음 빠르고 끝에 감속) 이동한다.
- [ ] 대사가 아래 띠 안에 두 줄 가운데 정렬로 한 글자씩 나오고, 초상화가 좌우로 천천히 기운다.
- [ ] 어드민 왼클릭: 타자 중이면 전체 표시, 다 나온 뒤면 다음 대사. 마지막 뒤에는 띠와 패널이 빠지고 모두 원래 자리·모드로 돌아온다.
- [ ] 컷씬 중 접속한 플레이어도 함께 보고, 나간 플레이어는 다시 접속하면 로비로 돌아온다.
